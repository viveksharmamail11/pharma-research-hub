# Journal of Pharmaceutical Research & Innovation (JP+)

A modern, responsive, static scholarly-journal website designed for GitHub Pages or Netlify. It uses HTML, CSS and vanilla JavaScript only — no server or database is required.

## Included
- Modern responsive homepage and navigation
- About / aims & scope
- Current issue
- Archives
- Editorial board / governance
- Editorial and publication policies
- Manuscript submission checklist
- Contact page
- Article HTML template with scholarly metadata placeholders
- Custom 404 page
- `robots.txt` and `sitemap.xml`
- Web manifest and favicon
- Mobile navigation and lightweight client-side filtering support

## Important launch checklist
1. Replace the placeholder editorial-board names with real, verified appointments.
2. Replace `journal.email@example.com` everywhere with the dedicated editorial email.
3. Connect an approved Google Form or journal-management system to `submit.html` before accepting manuscripts.
4. Formally adopt the final peer-review, ethics, copyright/license, corrections, fees and complaints policies.
5. Add ISSN only after it is officially assigned.
6. Add DOI information only after a DOI registration workflow is actually established.
7. Do not claim indexing, UGC/recognized status, accreditation, impact factor, Scopus, Web of Science, PubMed or Google Scholar inclusion until the relevant status is genuinely confirmed.
8. For every published article, create a unique HTML article/abstract page and link to its searchable-text PDF. Add correct citation metadata to that article page.
9. Update `sitemap.xml` with every published article URL.

## Google Scholar-oriented article structure
Each article should have its own URL, a visible complete abstract, clear title and author names, references, and appropriate citation metadata. See Google's publisher/webmaster guidance before launch.

## GitHub Pages
Keep `index.html` at repository root. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`. GitHub Pages publishes static HTML/CSS/JS directly from the repository.
